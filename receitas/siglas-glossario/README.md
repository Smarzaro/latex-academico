# Siglas, abreviaturas e glossário

Receitas para a lista de siglas, a lista de abreviaturas e o glossário de um trabalho acadêmico
(ABNT NBR 14724). Os exemplos compiláveis estão em
[`exemplos/siglas/`](../../exemplos/siglas/).

| Receita | O que resolve |
|---|---|
| [01 – Siglas com `acro`](01-siglas-com-acro.md) | Declarar, usar no texto (por extenso na primeira vez) e imprimir a lista |
| [02 – Lista de abreviaturas](02-lista-de-abreviaturas.md) | Uma lista própria para `p.`, `ed.`, `art.` (separada das siglas) |
| [03 – Glossário](03-glossario.md) | Termos técnicos com definições, em elemento pós-textual |

A NBR 14724 prevê a lista de abreviaturas e siglas, em ordem alfabética e com o significado por
extenso, e recomenda uma lista própria para cada tipo; a lista de símbolos segue a ordem em que
eles aparecem no texto. O formato das listas é livre.
