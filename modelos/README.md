# Modelos

Preâmbulos mínimos para começar um documento.

| Arquivo | Para quê |
|---|---|
| [`abnt-minimo.tex`](abnt-minimo.tex) | Documento ABNT mínimo: `abntex2`, `biblatex-abnt`, um capítulo e a lista de referências |

Para um **modelo completo de TCC** (capa, folha de rosto, folha de aprovação, resumo, listas,
siglas), use a classe [`abntex2-ufv`](https://github.com/Smarzaro/abntex2-ufv) (Sistemas de
Informação da UFV, Campus Rio Paranaíba) ou o modelo da sua instituição.
