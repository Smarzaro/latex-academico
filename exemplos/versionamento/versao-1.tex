\section{Introdução}

O uso de dispositivos móveis em sala de aula cresceu nos últimos anos. Este trabalho avalia o
impacto desse uso no desempenho dos alunos de uma turma de graduação.

Os dados foram coletados por meio de questionários aplicados no fim do semestre.

\section{Conclusão}

Os resultados indicam que o uso dos dispositivos não altera o desempenho.
